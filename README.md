# TalcoProg

Éditeur HTML, CSS et JS avec exécution instantanée (code, résultat ou fenêtre partagée), plus Python (dans le navigateur), C++ et Kotlin (compilés en ligne).

- React (JSX) directement, bouton Tout réinitialiser
- Dossiers de projet avec plusieurs fichiers (.html, .css, .js), sauvegardés dans le navigateur
- Bibliothèque de blocs de code et guides, du débutant au confirmé
- Export en page .html fusionnée ou en .json, réimport du .json
- PWA installable, responsive

## Mise en ligne
Déposez tous les fichiers à la racine du dépôt (ou utilisez le workflow GitHub Actions avec le zip).

## Raccourcis
- Ctrl+S : exporter la page en .html
- Tab : indenter
