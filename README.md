# TalcoProg

Éditeur HTML avec exécution instantanée : code, résultat, ou fenêtre partagée.
Import / export de fichiers .html, glisser-déposer, sauvegarde automatique, PWA installable.

## Mise en ligne (GitHub Pages)
Déposez tous les fichiers à la racine du dépôt, puis activez GitHub Pages.

## Raccourcis
- Ctrl+S : exporter en .html
- Tab : indenter
